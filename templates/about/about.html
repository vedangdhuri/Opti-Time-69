Project Overview

What is Opti-Time?

Opti-Time is a full-stack web application that automates the creation of college timetables using a constraint-based scheduling algorithm. Traditional manual scheduling is error-prone, time-consuming, and frequently leads to teacher clashes, free periods, and unbalanced workloads. Opti-Time eliminates all of these problems by treating timetable generation as a constraint satisfaction problem (CSP).

The system accepts structured input — divisions, teachers, subjects, and credit hours — and deterministically produces a full week's schedule for every division simultaneously. Practical subjects are automatically paired into continuous 2-hour blocks and distributed evenly across the week. No two teachers are assigned to the same time slot for the same division, and each teacher's weekly workload is enforced within defined limits.

Beyond generation, Opti-Time provides a suite of analytical tools: real-time workload dashboards, conflict detection validators, division-wise and teacher-wise timetable views, and printable PDF-ready outputs — all accessible from a single, unified admin interface.

Algorithm

How the Scheduler Works

1

Input Collection

Admin enters divisions, subjects, teachers, credit hours, and practical flags.

2

Slot Allocation

Time slots (Mon–Sat, periods 1–6) are ranked and matched to subjects by priority.

3

Constraint Check

Each assignment is verified against teacher availability, division limits, and workload caps.

4

Practical Pairing

Lab subjects are auto-paired into continuous 2-hour blocks with batch rotation logic.

5

Output & Export

Final timetables are stored in the database, rendered on-screen, and available for print.

Practical Block Logic

Teacher Timetable View

Every teacher gets a personalised weekly view showing exactly which division and subject they teach each period.

Dedicated print stylesheets render clean, paginated timetables suitable for notice boards and faculty handouts.

Admin Control Panel

Django's admin interface lets authorised users manage all master data — subjects, teachers, divisions — without touching code.

Overall Analytics

Institute-wide statistics: subject distribution, period utilisation rates, and multi-division comparison charts.
